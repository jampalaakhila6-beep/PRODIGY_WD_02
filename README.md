
# Stopwatch Web Application ⏱️

A simple and responsive stopwatch application built using HTML, CSS, and JavaScript. It allows users to start, stop, reset, and record lap times.

## Features
- Start stopwatch
- Stop stopwatch
- Reset stopwatch
- Record lap times
- Attractive UI with background image
- Responsive design

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Structure
# Stopwatch Web Application ⏱️

│── index.html      # Main structure
│── style.css       # Styling
│── script.js       # Stopwatch functionality
│── sp.png          # Background image
│── README.md       # Project documentation

## How to Run
1. Download or clone the repository
2. Open `index.html` in any browser
3. Use Start, Stop, Reset, and Lap buttons
